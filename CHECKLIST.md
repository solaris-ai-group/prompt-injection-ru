# Чек-лист перед выкатом агента в прод

Проверяется до первого живого клиента, а не после инцидента.

## Права и действия

- [ ] Агент не имеет доступа к операциям, которые ему не нужны по задаче
- [ ] Необратимые действия требуют подтверждения человеком
- [ ] Есть лимиты: суммы, количество операций, частота
- [ ] Ключи выданы отдельно под агента, а не взяты общие
- [ ] Права можно отозвать за минуту, не выкатывая релиз

## Контекст

- [ ] Внешние данные подаются размеченными как данные, а не как указания
- [ ] Разметку нельзя подделать содержимым пользовательского сообщения
- [ ] История одного клиента не попадает в контекст другого
- [ ] Загруженные файлы обрабатываются как недоверенные данные

## Ответ

- [ ] Ответ проверяется на фрагменты системного промпта и служебные маркеры
- [ ] Ответ проверяется на ключи, токены и внутренние адреса
- [ ] При срабатывании проверки уходит безопасный ответ, а не молчание

## Наблюдаемость

- [ ] Каждое срабатывание защиты пишется в лог с исходным сообщением
- [ ] Есть сигнал в мессенджер при серии срабатываний
- [ ] Логи хранятся достаточно долго, чтобы разобрать отложенную атаку

## Проверка

- [ ] Прогнан набор проверок из `probes/`
- [ ] Проверки прогнаны повторно после каждого изменения промпта
- [ ] Кто-то из команды пытался сломать бота руками и не смог за 15 минут
